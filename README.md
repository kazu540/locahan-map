# ロケハン地図

撮影のロケハン用に、気になった場所を **写真・タグ・メモと一緒に記録** し、その場所の **光の情報（太陽の位置・ゴールデンアワーなど）** と **天気** を自動で残して、あとから地図や一覧で見返すための iPhone 向けアプリです。

- アプリのアドレス：**https://kazu540.github.io/locahan-map/**
- データはすべて **iPhoneの中** に保存されます（サーバーやログインはありません）。
- 費用はかかりません。

---

## 1. はじめに：ホーム画面に追加する

Safari で開いたままでも使えますが、**ホーム画面に追加して使うのがおすすめ** です。アプリのように全画面で使えて、保存したデータも消えにくくなります。

1. iPhone の **Safari** で上のアドレスを開く
2. 画面下（または上）の **共有ボタン**（□に↑のマーク）を押す
3. メニューを下にスクロールして **「ホーム画面に追加」** を押す
4. 右上の **「追加」** を押す
5. 以後は、ホーム画面の **「ロケハン」** アイコンから開く

> ⚠ Safari で開いたときと、ホーム画面から開いたときでは、**保存場所が別** です。Safari で記録したデータを引き継ぐには、Safari 側で「バックアップを書き出す」→ ホーム画面のアプリで「バックアップから読み込む」を行ってください（[3. バックアップ](#3-バックアップの取り方戻し方)）。

## 2. 使い方

### 記録する（現地で）
1. 右下のオレンジの **＋** を押す
2. 現在地（GPS）と日時が自動で入り、**光の情報** と **天気** も自動で計算・取得されます
3. 必要に応じて次を追加し、**保存** を押す
   - **写真**：「撮る・選ぶ」から（複数枚OK。保存前に自動で小さくします）
   - **撮る向き**：「向きを測る」でカメラを撮りたい方向に向ける → 「この向きで記録」（または「手で選ぶ」）
   - **タグ**：歩道橋・坂・人が少ない・階段・路地・川沿い・夜景向き（「＋ タグを追加」で自由に追加）
   - **場所の名前・メモ・新宿／東京駅からの行き方**（すべて任意）

### 見返す
- **地図タブ**：写真入りのピンをタップすると、下から写真と光の情報が出ます。「詳細を見る」で全部の情報へ。
  - 何も選んでいないときは、地図の中心の **今日の光**（日の出・日没・次のゴールデンアワー）を表示します。
  - 右上のボタン：➤ 現在地へ／⛶ すべての記録を表示
- **一覧タブ**：写真のカードで一覧表示。
- **タグで絞り込み**：地図と一覧の上のタグを押します。複数選ぶと **すべてを含む記録だけ**（例：「歩道橋」かつ「坂」）。「すべて」で解除。

### 光を確認する（撮影日の計画）
詳細画面の **「光を見る」** で、日付と時刻を変えて光を計算し直せます。
- スライダーで時刻を動かす／「日の出」「夕ゴールデン」などのボタンで一気に移動
- **コンパス図**：オレンジの丸が太陽の方角。外側の薄い弧はその日に太陽が通る範囲
- **高さの弧**：太陽の高さ（0°＝地平線、90°＝真上）
- **時間帯のバー**：オレンジ＝ゴールデンアワー、青＝ブルーアワー
- **1日の太陽の動き**：グラフ（タップでその時刻へ）と1時間ごとの表
- 向きを記録してあれば、その日時だと **順光／逆光／サイド光** のどれになるかを表示

### 記録を直す・消す
詳細画面の左上 **「編集」** で、写真・タグ・メモ・向き・天気などを直せます。一番下の **「この記録を削除」** で削除できます（元に戻せません）。

### タグを管理する
**設定タブ → タグ** で、タグの追加・名前の変更・削除ができます。名前を変えると、そのタグが付いた記録もすべて新しい名前になります。

## 3. バックアップの取り方・戻し方

iPhone の Safari は、しばらく使わないアプリのデータを消すことがあります。また機種変更のときも必要になるので、**ときどきバックアップを取ってください**。（2週間以上バックアップしていないと、設定タブに赤い点が付きます）

### 書き出す（保存する）
1. **設定タブ → 「バックアップを書き出す」** を押す（ファイルを作ります）
2. ボタンが **「ファイルに保存する（○MB）」** に変わったら、もう一度押す
3. 共有メニューで **「"ファイル"に保存」** を選び、**iCloud Drive** などに保存する

ファイル名は `locahan-backup_日付_時刻.zip` です。写真もすべて入っています。

### 読み込む（元に戻す）
1. **設定タブ → 「バックアップから読み込む」** を押す
2. 保存しておいた `locahan-backup_….zip` を選ぶ

今ある記録は消えません。同じ記録は新しい内容で置き換え、ない記録は追加します。

### 機種変更のとき
古い iPhone で書き出し → iCloud Drive に保存 → 新しい iPhone でアプリをホーム画面に追加 → 読み込み。

## 4. 困ったとき

| 困りごと | 対処 |
|---|---|
| 現在地が取れない | iPhone の「設定」→「プライバシーとセキュリティ」→「位置情報サービス」をオン。その中の「Safari Webサイト」を「使用中のみ」に。屋内では誤差が大きくなります。取れないときは緯度・経度の手入力でも記録できます。 |
| コンパス（向き）が使えない | 「向きを測る」で許可を求められたら「許可」。一度拒否した場合は、アプリを閉じて開き直すと再度聞かれます。使えないときは「手で選ぶ」でも記録できます。数字がずれるときは iPhone を大きく8の字に動かしてください。 |
| 地図が灰色で表示されない | 地図の絵柄はインターネットから読み込みます。電波のある場所で開き直してください（記録や光の計算は圏外でも使えます）。 |
| 天気が出ない | 電波がないと取得できません。保存しておけば、電波が戻ったとき・次にアプリを開いたときに自動で取得します。天気の行の「変更」から手で選ぶこともできます。 |
| 新しい版にならない | アプリを完全に閉じて（下からスワイプして上に払う）開き直してください。設定タブの「アプリの版」で確認できます。 |
| データが消えた | バックアップから読み込んでください（[3. バックアップ](#3-バックアップの取り方戻し方)）。Safari とホーム画面のアプリで保存場所が別なので、もう片方にデータが残っていないかも確認してください。 |
| 容量が気になる | 設定タブの「使っている容量」で確認できます。写真は1枚あたり数百KBに小さくして保存しています。 |

## 5. 機能を直したい・増やしたいとき

Claude（Claude Code）に、日本語でやってほしいことを伝えてください。例：

> GitHub の `kazu540/locahan-map`（ロケハン地図アプリ）で、一覧を日付の古い順にも並べ替えられるようにしてほしい

直したものは GitHub に送られ、1〜2分で公開中のアプリに反映されます。記録したデータは iPhone の中にあるので、アプリを直しても消えません（大きな変更の前にはバックアップがおすすめです）。

## 6. しくみ（参考）

- iPhone の Safari で動く Web アプリ（PWA）。HTML・CSS・JavaScript のみで、特別な準備や変換は不要です。
- 公開：GitHub Pages（`main` ブランチの中身がそのまま公開されます）
- 保存：IndexedDB（iPhone 内の保存場所）。写真は保存前に長辺 2048px の JPEG に縮小
- オフライン：Service Worker（`sw.js`）でアプリ本体を保存
- ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/app.css` | 見た目（色はファイル先頭でまとめて設定、ダークモード対応） |
| `js/app.js` | 画面の動き全体 |
| `js/db.js` | データの保存 |
| `js/photos.js` | 写真の縮小 |
| `js/light.js` / `js/lightpanel.js` | 太陽の計算と図 |
| `js/map.js` | 地図とピン |
| `js/weather.js` | 天気の取得 |
| `js/compass.js` | コンパス |
| `js/backup.js` / `js/zip.js` | バックアップの書き出し・読み込み |
| `js/time.js` | 日本時間の表示 |
| `sw.js` / `manifest.webmanifest` / `icons/` | ホーム画面用・オフライン用 |
| `vendor/` | 同梱しているライブラリ |
